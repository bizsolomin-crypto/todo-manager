# Проверка деплоя

## ✅ Что должно произойти автоматически:

После добавления workflow файла GitHub Actions автоматически запустит деплой.

## 🔍 Как проверить:

### 1. Проверьте статус деплоя:

Зайдите на: https://github.com/bizsolomin-crypto/todo-manager/actions

Вы должны увидеть:
- ✅ Запущенный workflow "Deploy to GitHub Pages"
- ✅ Процесс сборки (build)
- ✅ Процесс деплоя (deploy)

Если видите желтый кружок ⏳ - деплой в процессе (2-3 минуты)
Если видите зеленую галочку ✅ - деплой успешен!
Если видите красный крестик ❌ - есть ошибка (проверьте логи)

### 2. Проверьте настройки GitHub Pages:

Зайдите на: https://github.com/bizsolomin-crypto/todo-manager/settings/pages

Должно быть:
- **Source**: `GitHub Actions`
- **Custom domain**: (пусто, если не настроено)

### 3. Откройте ваше приложение:

После успешного деплоя (зеленая галочка в Actions) ваше приложение будет доступно по адресу:

**https://bizsolomin-crypto.github.io/todo-manager/**

---

## ⚠️ Если деплой не запустился:

1. Проверьте, что workflow файл добавлен: https://github.com/bizsolomin-crypto/todo-manager/tree/main/.github/workflows
2. Если файла нет - добавьте его (см. ADD_WORKFLOW.md)
3. Если файл есть, но деплой не запустился - нажмите на вкладку **Actions** → **"Run workflow"** → **"Run workflow"**

---

## 🔧 Если есть ошибки:

1. Откройте workflow в Actions
2. Нажмите на failed job (красный крестик)
3. Проверьте логи - там будет указана причина ошибки

**Частые проблемы:**
- ❌ Секреты не добавлены → добавьте VITE_SUPABASE_URL и VITE_SUPABASE_ANON_KEY
- ❌ GitHub Pages не настроен → настройте в Settings → Pages
- ❌ Ошибка сборки → проверьте логи build job

---

## ✅ После успешного деплоя:

Ваше приложение будет работать и доступно по ссылке выше!
Все задачи будут сохраняться в Supabase (если таблица создана).
