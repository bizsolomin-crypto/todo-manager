# Как проверить, что SQL выполнился правильно

## Способ 1: Проверка через SQL Editor в Supabase

1. Зайдите в Supabase → **SQL Editor**
2. Выполните этот запрос:

```sql
SELECT column_name, data_type 
FROM information_schema.columns 
WHERE table_name = 'todos' 
AND table_schema = 'public';
```

**Ожидаемый результат:** Должны быть колонки:
- `id` (bigint)
- `text` (text)
- `completed` (boolean)
- `category` (text) ← **ЭТА КОЛОНКА ДОЛЖНА БЫТЬ!**
- `created_at` (timestamp)
- `updated_at` (timestamp)

---

## Способ 2: Проверка данных

Выполните в SQL Editor:

```sql
SELECT * FROM todos LIMIT 5;
```

**Ожидаемый результат:** 
- Все записи должны иметь колонку `category`
- Значение должно быть `'none'` или другое (если вы задавали категории)

---

## Способ 3: Проверка через Table Editor

1. Зайдите в Supabase → **Database** → **Tables** → **todos**
2. Посмотрите на колонки таблицы
3. Должна быть колонка **`category`** типа **text**

---

## Способ 4: Проверка в приложении

1. Откройте ваше приложение: http://localhost:5173
2. Откройте консоль браузера (F12 → Console)
3. Посмотрите на сообщения:
   - ✅ Если видите "Supabase подключен" - всё хорошо
   - ❌ Если видите ошибку про колонку category - SQL не выполнился

4. Попробуйте добавить новую задачу с категорией
5. Если ошибка исчезла - всё работает!

---

## Что должно произойти после выполнения SQL:

✅ Колонка `category` добавлена в таблицу  
✅ Все существующие задачи получили `category = 'none'`  
✅ Новые задачи могут сохранять категорию  
✅ Ошибка в приложении исчезнет  

---

## Если что-то не так:

### Колонка не появилась:
- Проверьте, что SQL выполнился без ошибок
- Попробуйте выполнить SQL ещё раз
- Убедитесь, что вы в правильном проекте

### Ошибка всё ещё есть:
- Обновите страницу приложения (F5)
- Очистите кеш браузера (Ctrl+Shift+R)
- Проверьте консоль браузера на другие ошибки

---

**Если всё правильно - ошибка должна исчезнуть!** 🎉
