# Инструкция по деплою приложения

Это пошаговая инструкция для деплоя вашего To-Do приложения с использованием Supabase и GitHub.

## Шаг 1: Настройка Supabase

### 1.1 Создайте проект в Supabase

1. Перейдите на [supabase.com](https://supabase.com)
2. Войдите в свой аккаунт (или создайте новый)
3. Нажмите "New Project"
4. Заполните данные:
   - **Name**: любое имя (например, "todo-app")
   - **Database Password**: придумайте надежный пароль (сохраните его!)
   - **Region**: выберите ближайший регион
5. Нажмите "Create new project"
6. Подождите 2-3 минуты, пока проект создается

### 1.2 Создайте таблицу в базе данных

1. В вашем проекте Supabase перейдите в **SQL Editor** (в левом меню)
2. Откройте файл `supabase-setup.sql` из этого проекта
3. Скопируйте весь SQL код из файла
4. Вставьте его в SQL Editor в Supabase
5. Нажмите "Run" (или F5)
6. Должно появиться сообщение об успешном выполнении

### 1.3 Получите ключи API

1. В проекте Supabase перейдите в **Settings** (настройки) → **API**
2. Найдите следующие значения:
   - **Project URL** - скопируйте этот URL
   - **anon public** key - скопируйте этот ключ (начинается с `eyJ...`)

Сохраните эти значения - они понадобятся позже!

## Шаг 2: Настройка GitHub репозитория

### 2.1 Создайте репозиторий на GitHub

1. Перейдите на [github.com](https://github.com)
2. Войдите в свой аккаунт
3. Нажмите кнопку "+" в правом верхнем углу → "New repository"
4. Заполните:
   - **Repository name**: например, "todo-manager"
   - **Description**: "To-Do менеджер на React"
   - Выберите **Public** (или Private, если хотите)
   - **НЕ** ставьте галочки на "Add a README file" и других опциях
5. Нажмите "Create repository"

### 2.2 Загрузите код в GitHub

Откройте терминал в папке проекта и выполните команды:

```bash
# Инициализация git (если еще не сделано)
git init

# Добавление всех файлов
git add .

# Первый коммит
git commit -m "Initial commit: To-Do менеджер"

# Добавление удаленного репозитория (замените YOUR_USERNAME и YOUR_REPO на свои)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git

# Отправка кода на GitHub
git branch -M main
git push -u origin main
```

**Важно**: Замените `YOUR_USERNAME` на ваш GitHub username и `YOUR_REPO` на имя вашего репозитория.

### 2.3 Настройте GitHub Pages

1. В вашем репозитории на GitHub перейдите в **Settings** → **Pages**
2. В разделе "Source" выберите:
   - **Source**: "GitHub Actions"
3. Сохраните изменения

### 2.4 Добавьте секреты GitHub

1. В репозитории перейдите в **Settings** → **Secrets and variables** → **Actions**
2. Нажмите "New repository secret"
3. Добавьте два секрета:

   **Первый секрет:**
   - **Name**: `VITE_SUPABASE_URL`
   - **Secret**: вставьте Project URL из Supabase (который вы скопировали в шаге 1.3)
   - Нажмите "Add secret"

   **Второй секрет:**
   - **Name**: `VITE_SUPABASE_ANON_KEY`
   - **Secret**: вставьте anon public key из Supabase (который вы скопировали в шаге 1.3)
   - Нажмите "Add secret"

## Шаг 3: Создайте файл .env для локальной разработки

1. В папке проекта создайте файл `.env` (скопируйте из `.env.example`)
2. Откройте файл `.env` и заполните:

```
VITE_SUPABASE_URL=ваш_project_url_из_supabase
VITE_SUPABASE_ANON_KEY=ваш_anon_key_из_supabase
```

3. Сохраните файл

**Важно**: Файл `.env` уже добавлен в `.gitignore`, поэтому он не попадет в GitHub.

## Шаг 4: Деплой

### Автоматический деплой

После того как вы:
1. ✅ Создали Supabase проект и таблицу
2. ✅ Загрузили код на GitHub
3. ✅ Добавили секреты в GitHub
4. ✅ Настроили GitHub Pages

Деплой произойдет автоматически при каждом push в ветку `main`!

### Проверка деплоя

1. Перейдите в ваш репозиторий на GitHub
2. Откройте вкладку **Actions**
3. Вы должны увидеть процесс деплоя (может занять 2-3 минуты)
4. После успешного деплоя перейдите в **Settings** → **Pages**
5. Там будет ссылка на ваше приложение (например: `https://YOUR_USERNAME.github.io/YOUR_REPO/`)

## Шаг 5: Обновление приложения

Каждый раз, когда вы хотите обновить приложение:

1. Внесите изменения в код
2. Выполните в терминале:
   ```bash
   git add .
   git commit -m "Описание изменений"
   git push
   ```
3. GitHub Actions автоматически задеплоит новую версию!

## Устранение проблем

### Приложение не работает после деплоя

1. Проверьте, что секреты в GitHub правильно добавлены
2. Убедитесь, что таблица в Supabase создана
3. Проверьте логи в GitHub Actions (вкладка Actions)

### Ошибки при сборке

1. Убедитесь, что все зависимости установлены: `npm install`
2. Проверьте, что нет ошибок в коде: `npm run build`

### Данные не сохраняются

1. Проверьте, что Supabase ключи правильно настроены
2. Убедитесь, что RLS политики в Supabase разрешают операции
3. Проверьте консоль браузера на наличие ошибок
