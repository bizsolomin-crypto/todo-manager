# Где найти Project URL в Supabase

## Способ 1: В разделе General (самый простой)

1. В левом меню нажмите **"Settings"** (если еще не там)
2. В разделе **"PROJECT SETTINGS"** нажмите на **"General"** (первый пункт)
3. Вверху страницы вы увидите **"Reference ID"** и **"Project URL"**
4. Project URL будет выглядеть так: `https://xxxxx.supabase.co`

## Способ 2: На главной странице проекта (Dashboard)

1. Нажмите на **"Home"** или **"Dashboard"** в левом меню (иконка дома 🏠)
2. Вверху страницы, рядом с названием проекта, обычно отображается Project URL
3. Или в карточке "Project Settings" будет ссылка на URL

## Способ 3: В разделе API (не API Keys!)

1. В левом меню **Settings** → **API** (не "API Keys"!)
2. В самом верху страницы должен быть раздел с Project URL
3. Он обычно находится ПЕРЕД секциями с ключами

## Способ 4: По Reference ID

Если вы видите **Reference ID** (например, `juqkhwodgxbulkvvpvrj`), то Project URL будет:
```
https://juqkhwodgxbulkvvpvrj.supabase.co
```

---

## Важно!

Project URL НЕ находится в разделе "API Keys" - это другой раздел!
Нужно искать в:
- ✅ Settings → **General**
- ✅ Settings → **API** (основной раздел, не Keys)
- ✅ Dashboard (главная страница)
