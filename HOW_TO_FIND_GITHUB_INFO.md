# Где найти GitHub username и название репозитория

## 1. Как найти ваш GitHub username:

### Способ 1: В правом верхнем углу
1. Зайдите на [github.com](https://github.com) и войдите
2. В **правом верхнем углу** нажмите на ваш **аватар** (круглая картинка)
3. В выпадающем меню вверху будет ваш **username** (например, `sergey123`)

### Способ 2: В URL страницы
1. После входа на GitHub посмотрите на адресную строку браузера
2. Если вы на главной странице, URL будет: `https://github.com/ВАШ_USERNAME`
3. Или нажмите на ваш аватар → **"Your profile"** - URL будет содержать ваш username

### Способ 3: В настройках
1. Нажмите на аватар → **"Settings"**
2. В левом меню выберите **"Profile"**
3. Вверху будет поле **"Public profile"** с вашим username

---

## 2. Как найти название репозитория:

### Если вы уже создали репозиторий:

1. После создания репозитория GitHub покажет страницу с инструкциями
2. В **адресной строке браузера** будет URL вида:
   ```
   https://github.com/ВАШ_USERNAME/НАЗВАНИЕ_РЕПОЗИТОРИЯ
   ```
3. **НАЗВАНИЕ_РЕПОЗИТОРИЯ** - это то, что вы ввели в поле "Repository name" при создании

### Если вы еще не создали репозиторий:

1. При создании репозитория в поле **"Repository name"** введите любое имя, например:
   - `todo-manager`
   - `my-todo-app`
   - `todo-list`
   - или любое другое имя (без пробелов, можно использовать дефисы)

2. Это имя и будет названием репозитория

---

## Пример:

Если ваш username: `sergey123`
И вы назвали репозиторий: `todo-manager`

То команда будет:
```bash
git remote add origin https://github.com/sergey123/todo-manager.git
```

---

## Быстрая проверка:

После создания репозитория, посмотрите на URL в браузере:
```
https://github.com/ВАШ_USERNAME/НАЗВАНИЕ_РЕПОЗИТОРИЯ
```

Отсюда и возьмите оба значения!
