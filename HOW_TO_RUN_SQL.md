# Как выполнить SQL скрипт в Supabase - Пошаговая инструкция

## Что такое "выполнить SQL"?

SQL (Structured Query Language) - это язык для работы с базами данных. Когда мы говорим "выполнить SQL", это значит:
1. Открыть SQL Editor в Supabase
2. Вставить SQL код
3. Нажать кнопку "Run" (Запустить)
4. Код выполнится и изменит структуру вашей базы данных

---

## Пошаговая инструкция:

### Шаг 1: Откройте Supabase

1. Зайдите на [supabase.com](https://supabase.com)
2. Войдите в свой аккаунт
3. Выберите ваш проект (например, "todoshka" или "bizsolomin")

### Шаг 2: Найдите SQL Editor

1. В левом боковом меню найдите раздел **"SQL Editor"**
   - Иконка выглядит как `</>` или как лист с кодом
   - Обычно находится в разделе "Development" или "Database"

2. Нажмите на **"SQL Editor"**

### Шаг 3: Откройте файл с SQL кодом

1. В вашем проекте откройте файл `supabase-add-category.sql`
2. Скопируйте весь код из этого файла:

```sql
-- Миграция: добавление колонки category в таблицу todos
-- Выполните этот скрипт в SQL Editor вашего проекта Supabase

ALTER TABLE todos 
ADD COLUMN IF NOT EXISTS category TEXT DEFAULT 'none';

-- Обновляем существующие записи, у которых category NULL
UPDATE todos 
SET category = 'none' 
WHERE category IS NULL;
```

### Шаг 4: Вставьте код в SQL Editor

1. В SQL Editor вы увидите большое текстовое поле (как блокнот)
2. Вставьте скопированный SQL код в это поле
   - Можно удалить всё, что там было
   - Или просто вставить в конец

### Шаг 5: Выполните SQL

1. Найдите кнопку **"Run"** или **"Execute"** или **"▶"** (play)
   - Обычно находится в правом верхнем углу редактора
   - Или внизу справа
   - Или нажмите `Ctrl+Enter` (Windows) или `Cmd+Enter` (Mac)

2. Нажмите на эту кнопку

### Шаг 6: Проверьте результат

1. Внизу экрана появится результат выполнения
2. Если всё хорошо, вы увидите:
   - ✅ "Success" или "Query executed successfully"
   - Или сообщение о том, что колонка добавлена

3. Если есть ошибка, вы увидите красное сообщение с описанием проблемы

## Что делает этот SQL код?

```sql
ALTER TABLE todos 
ADD COLUMN IF NOT EXISTS category TEXT DEFAULT 'none';
```
**Перевод:** "Добавь в таблицу todos колонку category (если её ещё нет), тип TEXT, значение по умолчанию 'none'"

```sql
UPDATE todos 
SET category = 'none' 
WHERE category IS NULL;
```
**Перевод:** "Обнови все записи в таблице todos: установи category = 'none' для тех, у кого category пустая"

## После выполнения:

1. Обновите страницу вашего приложения (F5 или Cmd+R)
2. Ошибка должна исчезнуть
3. Категории будут сохраняться в Supabase

---

## Если что-то пошло не так:

### Ошибка "relation does not exist"
- Таблица todos не создана
- Выполните сначала `supabase-setup-clean.sql`

### Ошибка "permission denied"
- Проверьте, что вы вошли в правильный проект
- Убедитесь, что у вас есть права на изменение таблицы

### Кнопка "Run" не работает
- Убедитесь, что код скопирован полностью
- Проверьте, что нет синтаксических ошибок
- Попробуйте выполнить код построчно

---

## Альтернативный способ (через Table Editor):

Если SQL Editor не работает, можно добавить колонку через интерфейс:

1. Зайдите в **Database** → **Tables** → **todos**
2. Нажмите на иконку **"Add column"** или **"+"**
3. Заполните:
   - **Name**: `category`
   - **Type**: `text`
   - **Default value**: `none`
4. Нажмите **"Save"**

---
