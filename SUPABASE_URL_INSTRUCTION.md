# Где найти Project URL в Supabase

## Пошаговая инструкция:

1. **Зайдите на [supabase.com](https://supabase.com)** и войдите в свой аккаунт

2. **Выберите ваш проект** (кликните на него в списке проектов)

3. **В левом боковом меню** найдите и нажмите на **"Settings"** (Настройки)
   - Иконка выглядит как шестеренка ⚙️

4. **В настройках** найдите раздел **"API"** в левом меню и нажмите на него

5. **В разделе API** вы увидите несколько секций:
   - **Project URL** - это то, что вам нужно!
   - Он находится в самом верху страницы
   - Выглядит примерно так: `https://xxxxx.supabase.co`

6. **Скопируйте этот URL** - это и есть ваш Project URL

---

## Альтернативный способ:

Если не можете найти через Settings:
- Project URL также можно увидеть в **Dashboard** (главная страница проекта)
- Обычно он отображается в правом верхнем углу или в информации о проекте

---

## Важно:

Project URL должен выглядеть так:
```
https://juqkhwodgxbulkvvpvrj.supabase.co
```

(где `juqkhwodgxbulkvvpvrj` - это ваш Project Reference, который я вижу в вашем anon key)
